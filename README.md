# Campus Control - Student Management System

Campus Control is a backend application developed using Spring Boot for managing students, courses, and marks records. The system provides REST APIs for performing academic data management operations.

## Features

- Student Management
- Course Management
- Marks Management
- Add, Update, Delete Records
- View Student Details
- View Course Details
- Manage Student Marks
- MySQL Database Integration

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Project Structure

```
src/main/java
├── controllers
├── services
├── repositories
├── entities

```

## API Testing

REST APIs can be tested using Postman.
